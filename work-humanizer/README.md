# work-humanizer — work writing that doesn't read as AI

Also free and public at [phuryn/work-humanizer](https://github.com/phuryn/work-humanizer), with the evidence behind every rule; included here so one install carries it.

## Install

```bash
claude plugin marketplace add chiodipaulo/criterio
claude plugin install work-humanizer@criterio
```

Codex, Cursor and other agents: see the collection's root `README.md`.

## Skills (1)

- **work-humanizer** — Edit AI-sounding work writing so it reads like a careful person wrote it without changing what it says, or interview the writer and build the piece from their answers.
